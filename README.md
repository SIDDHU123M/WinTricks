# Basic Windows Tricks

C**omprehensive list of Windows 11 secrets, hidden tricks, advanced shortcuts, and power features** — from productivity boosters to system tweaks:

***

### **Secret Features & Hidden Modes**

#### 1. **God Mode**

*   Create a folder and name it:

    ```
    GodMode.{ED7BA470-8E54-465E-825C-99712043E01C}
    ```
* Gives you a master control panel with 200+ settings in one place.

***

#### 2. **Restart Graphics Driver Instantly**

* **Shortcut:** `Win + Ctrl + Shift + B`
* Use when screen freezes or glitches — restarts GPU drivers without rebooting.

***

#### 3. **Hidden Start Menu**

* **Right-click Start button** or press `Win + X`
* Access advanced tools like Device Manager, Event Viewer, PowerShell.

***

#### 4. **Secret Clipboard History**

* **Shortcut:** `Win + V`
* Enable it from settings, access past clipboard items, pin frequently used text.

***

#### 5. **Virtual Desktops**

* **Shortcut:** `Win + Ctrl + D` – New desktop
* **`Win + Ctrl + Left/Right`** – Switch
* Great for separating workspaces.

***

#### 6. **Emoji & Symbol Picker**

* **Shortcut:** `Win + .` (dot)
* Access emojis, kaomojis, and symbols.

***

#### 7. **Dynamic Refresh Rate (DRR)**

* Go to **Settings > Display > Advanced display**, enable DRR (if supported).
* Saves battery by adjusting refresh rate dynamically.

***

#### 8. **Shake to Minimize**

* Grab a window and **shake it** to minimize all others. Shake again to restore.

***

#### 9. **Hidden File Extension Changer**

* File Explorer > View > Show > **File name extensions**
* Rename files from `.txt` to `.bat`, etc.

***

#### 10. **Quick Launch Apps with Taskbar**

* Press `Win + [1–9]`
* Launch or switch to the corresponding pinned app on the taskbar.

***

#### 11. **Alt + Tab Tuning**

* Settings > System > Multitasking
* Choose to show only recent windows, or all tabs from Microsoft Edge.

***

#### 12. **Night Light + Color Filter Combo**

* Settings > Display > Night Light
* Then go to **Settings > Accessibility > Color Filters** for grayscale, invert, etc.

***

### **Power User Tools**

#### 13. **PowerToys**

* Free Microsoft toolset for power users.
* Features: FancyZones (window tiling), Color Picker, Keyboard Manager, Run launcher (`Alt + Space`).

***

#### 14. **Windows Terminal**

* Supports PowerShell, Command Prompt, WSL in tabs.
* Run as admin from `Win + X`.

***

#### 15. **WSL (Windows Subsystem for Linux)**

* Run full Linux distros natively.
*   Command to install WSL:

    ```bash
    wsl --install
    ```

***

### **System & UI Customization**

#### 16. **Taskbar & Start Menu Customization**

* Settings > Personalization
* Move taskbar icons to left, disable recommendations, more.

***

#### 17. **Hidden Startup Apps**

* `Ctrl + Shift + Esc` > Startup
* Disable heavy apps slowing boot.

***

#### 18. **Hidden Storage Analyzer**

* Settings > System > Storage > “Show more categories”
* View hidden data usage, clean temp files, manage cloud content.

***

#### 19. **Auto HDR & Game Mode**

* Great for gaming performance.
* `Settings > System > Display > HDR`
* Enable **Auto HDR** and **Game Mode**.

***

***

#### 21. **Screen Calibration Tool**

*   Run:

    ```
    dccw
    ```
* Walks you through adjusting brightness, contrast, gamma for better visuals.

***

#### 22. **Performance Monitor**

*   Run:

    ```
    perfmon
    ```
* Analyze system performance with real-time charts.

***

#### 23. **Steps Recorder**

*   Run:

    ```
    psr
    ```
* Automatically records steps and screenshots to help with troubleshooting.

***

#### 24. **File History Backup**

* Settings > Update & Security > Backup > "Add a drive"
* Keeps backup of user files over time, great recovery tool.

***

### **Hidden Menus & UIs**

#### 25. **Classic Control Panel**

*   Run:

    ```
    control
    ```
*   Or:

    ```
    explorer shell:::{21EC2020-3AEA-1069-A2DD-08002B30309D}
    ```

***

#### 26. **Hidden Troubleshooters**

* Settings > System > Troubleshoot > Other troubleshooters
* Has hidden diagnostics for audio, Bluetooth, keyboard, network, etc.
